How to make ↗ open the installed LabGorilla app (Brave)
  1. Open brave://flags, search for Desktop PWA Link Capturing, set it to Enabled and click Relaunch.
  2. Install LabGorilla as an app (install icon in the address bar of its web page).
  3. Open the app's settings in Brave (brave://apps → right-click LabGorilla → App settings) and switch on Open supported links.
  4. Click a ↗ here. It now opens in the LabGorilla app window instead of a browser tab.

Without this, ↗ still works: it opens LabGorilla in a normal browser tab.
